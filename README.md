# jangin — 캡컷 자동 편집 (부동산장인)

바탕화면의 bat 파일로 실행하는 웹 화면 프로그램(`src/webapp.py`)의 소스입니다.

> **이어서 작업할 때는 [`docs/작업현황.md`](docs/작업현황.md)부터 읽으세요.** (현재 상태, 남은 문제, 다음 작업)

## 2026-09 수정: 반복 발화 / 말끝 잘림

### 1. 두 번 반복해서 말한 것을 못 잡던 문제
- **원인 ①** 위스퍼가 앞 문맥을 보고 말을 매끄럽게 정리해서, 두 번 말한 것을 한 번으로 합쳐 받아적음
  → `src/transcribe.py`: `condition_on_previous_text=False` + 말더듬을 그대로 적은 예시 프롬프트
  (전사 방식이 바뀌어 기존 캐시는 자동으로 무시되고 한 번 다시 인식합니다)
- **원인 ②** 반복 감지가 '글자가 완전히 같을 때'만 동작 → 발음이 꼬인 테이크("감종가는")는 못 잡고,
  앞의 같은 부분("이 물건의")만 잘라서 꼬인 단어가 남음
  → `src/cutdetect.py`: 한글을 자모(ㄱㅏㅁ…)로 풀어 비슷하면 반복으로 판단. 숫자가 다르면 제외.

### 2. 컷이 빨라서 말끝이 잘리던 문제
- **원인** 컷 위치를 위스퍼 단어 시각으로만 정함. 위스퍼는 "~습니다" 같은 약한 어미를 일찍 끝난 것으로 잡음
- **해결** `src/audio_energy.py`(새 파일): 실제 소리 크기를 확인해서
  - 무음 컷은 소리가 진짜로 사그라든 뒤에 시작, 다음 말 첫소리가 올라오기 전에 끝
  - 반복/필러/AI 컷은 경계를 단어 사이 가장 조용한 지점으로 이동

### config.yaml 에 추가할 수 있는 설정 (안 넣어도 기본값으로 동작)

```yaml
cut:
  energy_refine: true            # 음량 기반 말끝 보호 (false면 예전 방식)
  energy_tail_margin: 0.12       # 말이 실제로 끝난 뒤 남길 여유(초). 아직 잘리면 0.2로
  energy_head_margin: 0.08       # 다음 말 시작 전 여유(초)
  repeat_fuzzy_threshold: 80     # 비슷한 반복 판정 기준. 낮추면 더 많이 잡음, 0이면 끔
  repeat_fuzzy_min_syllables: 4  # 이보다 짧은 말은 '비슷한 반복' 판정 안 함
whisper:
  verbatim: true                 # 반복/말더듬 그대로 받아적기 (false면 예전 방식)
```
